# 개선안 백테스트 사전 등록 (2026-10-28, 실행 전 작성 — 결과를 보고 바꾸지 않는다)

기본 규칙·데이터·체결은 SPEC.md(진입 당일 손절 수정본)와 같다. 비용은 모두 현실 비용 = 수수료 0.015% + 1틱 + 매도세 0.20% (기존 변형 B).
기간 5·10·20·30년 각각 1억에서 시작. **표본외(OOS) = 2021-10-28 ~ 2026-10-27** (= 5년 기간). 판정은 OOS 성과와 KOSPI 대비로 한다.

## 설정 (8개)
| id | 내용 | 근거 출처 |
|---|---|---|
| B0 | 기존 규칙(기준선) | — |
| S1 | 신호일 ATR14/종가 ≤ 4.5% 인 종목만 주문 | 30년 거래 진단(OOS 포함 데이터로 고른 값 → 오염 가능) |
| S1b | 손절 = max(7%, 2×ATR14%) (수량은 같은 1% 위험으로 줄어듦), 필터 없음 | 펀드 기존 규칙(2×ATR) — 외부 사전 규칙 |
| S2 | 기준가가 신호일 종가의 +5% 이내일 때만 주문 | 미너비니·오닐 '피벗 5% 이내' — 외부 사전 규칙 |
| S3 | 갭 체결 금지: t+1 시가 ≥ 기준가면 매수 안 함(장중 돌파만) | 진단(갭 체결 당일 손절 50%) |
| S4 | 거래량 확인 돌파: t일 종가 ≥ t−1일 기준가 그리고 t일 거래량 ≥ 50일 평균 거래량×1.5 → t+1 시가 매수(갭 상관없음). 진입가 = t+1 시가, 손절·익절은 동일 | 오닐·미너비니 거래량 조건 — 외부 사전 규칙 |
| C1 | S1 + S2 + S3 | 진단 기반 조합 |
| C2 | S1b + S2 + S3 | 외부 사전 규칙 위주 조합(오염 적음) |

- R(손절폭 배수)은 S1b·C2 에선 실제 손절폭으로 나눈다.
- 다중 비교 주의: 8개를 시험하므로 가장 좋은 하나를 고르면 우연일 수 있다. OOS에서 B0·KOSPI를 모두 이기고, IS(2021-10-28 이전, 30년 기간 기준)에서도 B0보다 나아야 '개선'으로 본다.
