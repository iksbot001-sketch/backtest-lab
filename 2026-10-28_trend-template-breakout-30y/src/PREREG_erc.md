# 펀드 E·R·CR 위험관리 덧씌우기 사전 등록 (2026-10-28, 실행 전 작성 — 결과를 보고 바꾸지 않는다)

질문(대표): 책 방식에 포트폴리오 관리에서 본 리스크·익스포저·커런트 익스포저(E·R·CR) 관리와 '리스크 1%만 감내'를 적용하면 수익률·MDD·샤프가 어떻게 바뀌나.

## 정의 (research/portfolio_20261005/BRIEF.md, office cro/pm 스레드)
- E = 포지션 평가액 / NAV. 1R = NAV × 2%.
- ATR%_eff = max(ATR14/종가, 최근 252거래일 ATR% 중앙값) — CRO (c) ATR 바닥값.
- 포트폴리오 CR = Σ E × ATR%_eff (NAV 대비 하루 평균 흔들림). 상한은 NAV의 2.0% (= 1R, PM '2차 목표 2.0%' = CRO (b) 상관 1·3×ATR 갭 스트레스 6%와 같은 값).

## 기존(비교 기준) — 이미 들어 있는 것
- 1회 거래 손절 위험 = NAV × 1%, 열린 손절 위험 합계 ≤ NAV × 3%. 손절·청산 규칙은 B0(책) / C2(개선) 그대로. 비용 = 변형 B.

## 덧씌우는 규칙 (erc)
1. **CR 상한(신규):** 새로 살 때 포트폴리오 CR + 새 종목 CR ≤ 상한 이 되도록 수량을 줄인다(1주 미만이면 안 삼). 계산은 신호일 종가 기준.
2. **CR 초과 감축:** 장 마감 후 포트폴리오 CR 이 상한의 1.2배를 넘으면(PM: 20% 넘게 초과할 때만), 다음 날 시가에 모든 보유 종목을 같은 비율로 줄여 상한에 맞춘다.
3. **유동성:** 한 종목 매수액 ≤ 20일 평균 거래대금의 10% (CRO (e)).
4. **낙폭 브레이크:** NAV가 고점 대비 −10% 아래면 1회 손절 위험 0.5%, CR 상한 절반. −5% 위로 회복하면 해제 (PM '펀드 낙폭 −10% 넘으면 상한 축소').
5. 1회 손절 위험 1%, 열린 손절 위험 3% 는 그대로.

## 설정 (4개 신규 × 4기간)
| id | 내용 |
|---|---|
| B0E | 책 규칙 + erc, CR 상한 2.0% |
| C2E | 개선 규칙 + erc, CR 상한 2.0% |
| B0E1 | 책 규칙 + erc, CR 상한 1.0% ('리스크 1%' 를 포트폴리오 하루 흔들림 1% 로 엄격하게 읽은 버전) |
| C2E1 | 개선 규칙 + erc, CR 상한 1.0% |

## 판정
- 기준선 B0·C2(이미 실행) 대비 CAGR·MDD·Sharpe·Sortino·평균 E·평균 CR 을 비교. KOSPI 도 함께.
- 'MDD 개선' = 4기간 모두 MDD 가 기준선보다 작음. '위험조정 개선' = 30년 Sharpe 가 기준선보다 높고 OOS(2021-10-28~) Sharpe 도 낮아지지 않음.
- 다중 비교: 이번 4개를 앞선 8개에 더해 총 12개 시험. 생존편향(상장폐지 제외) 그대로.
