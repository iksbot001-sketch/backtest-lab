## 2. 신호 정의 (고정)
- **z_t = (V_t − mean(V, t−10y..t)) / sd(V, t−10y..t)**, 직전 10년(월간 120개월 / 일간 2,520거래일) **후행 롤링**. 최소 8년 데이터부터 산출.
  - 대조용으로 '현재 시점 10년 창(정적)' z도 계산하나 **미래 정보 포함**이므로 판정에 쓰지 않는다(그림 설명용).
  - (LESSON HIT: 추세성 밸류에이션 지표 → 롤링 10년 평균 = 사전 등록한 디트렌딩 방법)
- 구간: z ≥ +2 과열강 / +1 ≤ z < +2 과열 / −1 < z < +1 중립 / −2 < z ≤ −1 저평가 / z ≤ −2 저평가강.
- VIX: ≥30 공포, ≤14 안일. F&G: ≤25 극공포, ≥75 극탐욕.
  - 월간 집계(실행 전 확정): 공포 = 그 달 일간 VIX 최고값 ≥30, 안일 = 그 달 일간 VIX 평균 ≤14. F&G도 같은 방식(최저 ≤25 / 평균 ≥75).
- S&P500 multpl PER은 이익 발표 지연을 고려해 **1개월 추가 지연**해서 쓴다. KRX PER·PBR은 발표일 기준이라 추가 지연 없음. multpl PBR(분기)은 분기말 다음 3개월 지연.
- 결합(조건3): 매수 = z ≤ −1 AND (VIX ≥ 30 또는 F&G ≤ 25), 매도 = z ≥ +1 AND (VIX ≤ 14 또는 F&G ≥ 75).
- 금리(조건4) 세 가지: (a) 수준 DFF 구간(<1, 1–3, 3–5, ≥5%), (b) 12개월 변화 ≥ +1.0%p = 인상기 / ≤ −1.0%p = 인하기, (c) DFF − 직전 10년 평균 ≥ +1%p = 긴축.

## 3. 평가 (고정)
- 체결: 월말 신호 → 다음 달 첫 거래일 종가 체결(일간 신호는 t 종가 → t+1). +1개월 지연 민감도 추가. (LESSON HIT: t+1 체결·지연 테스트)
- 1차 지표: 구간별 이후 3·6·12개월 수익률 평균/중앙값/상승확률, 12개월 내 최대 추가하락, 무조건 평균 대비 차이.
- 회귀: 12개월 선행수익률 ~ z, **Newey-West(lag=12, 월간)** t값. (LESSON HIT: 겹치는 수익률)
- **독립 에피소드 수**: 같은 구간 진입 후 6개월 이내 재진입은 같은 에피소드. 에피소드 < 3 이면 판정 보류. (LESSON HIT: n=5~6 판정 보류, 에피소드 수 세기)
- 비중 전략(구간 → 주식비중): z≤−2 100% / −2<z≤−1 80% / 중립 60% / +1≤z<+2 40% / z≥+2 20%, 나머지 현금(무위험 0%).
  비교: 상수 60%(평균 노출 일치) · B&H 100% · **순환 이동 플라시보 1,000회**(신호 지속성 유지). 비용 0.015%+1틱 ≈ 편도 5bp.
  (LESSON HIT: 노출 일치 벤치마크, 순환 이동 플라시보)
- 하위기간: 전반/후반, 2016~2026 별도. 2026 사례 연구는 결과 보고에만 쓰고 기준 조정에 쓰지 않는다.

## 4. 판정 기준 (고정)
시장×지표별 '쓸 만한 시그널' = 아래 모두:
- J1 NW t(12개월 수익률 ~ z) ≤ −2.0 (z 높을수록 이후 수익률 낮음), Bonferroni 보정 후 유의(1차 검정 수로 나눈 α=0.05)
- J2 과열·저평가 각 구간 독립 에피소드 ≥ 3
- J3 비중 전략 Sharpe > 상수 60% Sharpe, 플라시보 상위 10% 이내
- J4 후반부(최근 절반)에서도 J1 부호 유지
J1~J4 모두 → '시그널', J1·J4만 → '참고 지표(비중 조절용)', 그 외 → '기각'.

## 9. 추가 등록 v4 (2026-11-18 밤, 결과 보기 전) — 일간·단기 검증
질문: 일간 신호로 좁히면 단기(5·20·60거래일) 반등·조정을 예측하는가. 월간 12개월 질문과는 다른 질문으로 본다.
LESSON HIT: 겹치는 수익률(이벤트 간 최소 간격으로 독립화) / 미확정 수익률 제외 / 사후 고정 기준선 금지 / 고회전 전략은 회전율×비용 사전 점검 / 노출 일치 벤치마크·순환 이동 플라시보.
- 지표 7개(일간 자료가 있는 것): 200일 이격도 5개(S&P500·NASDAQ100·SOX·KOSPI·KOSDAQ), KOSPI PBR(KRX 일간), KOSDAQ PBR.
  - KOSDAQ PBR 일간: 수집본이 월말뿐이라 '직전 월말 PBR/종가 비율 × 당일 종가'로 근사(장부가가 월중 바뀌면 오차, 미래 정보 없음). 같은 근사를 KOSPI에 적용해 실제 일간 PBR과의 오차를 보고한다.
- z: 직전 2,520거래일 롤링 평균·σ(최소 2,000일, 당일 포함).
- 이벤트: z가 −1 하향 돌파(매수), +1 상향 돌파(매도). 같은 종류 이벤트는 직전 60거래일 안에 있었으면 제외(독립화). 2차: ±2 돌파.
- 체결: t 종가 신호 → t+1 종가 진입. 수평선 h = 5·20·60거래일. 이벤트 수익 = log(P[t+1+h]/P[t+1]).
- 초과수익 = 이벤트 평균 − 같은 지수 전체 일자 평균(h 동일). 귀무분포: 무작위 날짜 같은 개수 추출 10,000회(미확정 h 제외) → 한쪽 p.
- 1차 검정: 7지표 × 2방향(−1 매수, +1 매도) × h=20 = 14 → Bonferroni 한쪽 p < 0.05/14 = 0.0036. h=5·60, ±2 돌파는 2차(탐색).
- 일간 비중 전략: 3절 비중표를 일간 z에 적용, t+1 종가 체결, 비용 편도 5bp(0.015%+1틱 근사)·10bp 민감도, 현금 0%. 비교: 평균 노출 같은 상수 보유, 순환 이동 플라시보(이동 ≥ 252일). 연간 회전율×비용도 보고.
- 판정(지표×방향): D1 초과수익 부호 맞음 & p < 0.0036 / D2 독립 이벤트 ≥ 8 / D3 일간 비중 전략 Sharpe > 노출 일치 상수 & 플라시보 ≥ 90% (지표 단위) / D4 이벤트를 시간순 반으로 나눈 후반부에서도 초과수익 부호 유지.
  모두 = 단기 시그널, D1·D4 = 단기 참고지표, 이벤트 < 8 = 판정 보류, 그 외 = 기각.
