# calc6 diff — 고정(미래 정보 포함) vs 롤링, 독립 재계산 (src/ 미열람)

코드 `calc6/recalc.py`(+진단 `diag*.py`), 결과 `calc6/out/recalc.csv`(6조합 × 5방식), `table.md`, `kospi_pbr_diag.txt`, 월수익 `ret_<조합>_<방식>.csv`(period,ret 월간).
방식: rolling(직전 120개월, 최소 96) / fixed(그 지표 전체 표본 평균·σ, ddof=1) / **fixed_cut**(fixed z를 rolling 시작월부터만 사용) / fixed_cutstats(평균·σ도 잘린 표본으로) / **expanding**(과거만 쓰는 누적 평균·σ, 최소 96개월 = 미래 정보 없음, 대조용 추가).
S&P PER = 쉴러 분기 말 E(+3개월 뒤부터), KOSPI 체결가 = ^KS11 월 첫 종가.

## 1. src 결과(out/hindsight_compare.csv)와 대조
- **12개월 NW t: 12행(롤링·고정 × 6) 전부 소수 3자리까지 일치.** 후반부 t, 시작월, 에피소드 수(fix_ep 4/5, 3/6, 3/0, 3/1, 2/2, 5/2)도 일치. 판정 12개 전부 일치(KOSPI PBR fixed만 '시그널').
- 전략 Sharpe(전략/상수 60%) 소수 2자리 일치.
- 차이 1: **순환 플라시보 백분위가 최대 0.019 어긋남**(예: KOSPI PBR rolling 0.716 vs 0.697, 나머지 ≤0.009). 이동 범위(12..N−12 포함/제외)·비용 규약 6가지를 바꿔 봐도 0.697은 재현 안 됨(0.714~0.716). 원인 미확정(src 미열람이라 확인 불가). 어떤 판정도 바뀌지 않음(J3 90% 선은 KOSPI PBR fixed 0.996, KOSDAQ PBR fixed 0.900 vs src 0.899 — 후자는 90% 경계에 걸리나 J1·J4 통과·J2 실패라 판정 보류는 동일).
- 차이 2(해소): KOSPI 체결가를 KRX 종가로 쓰면 t가 0.003~0.01 어긋남(0.3924 vs 0.3899, −3.0678 vs −3.0785). Yahoo ^KS11로 바꾸자 정확히 일치 → src는 ^KS11 사용. 두 종가 월 첫 값의 최대 상대차 2.8%.

## 2. 핵심 질문: fixed에서 KOSPI PBR이 J1~J4 전부 통과하는가
**예 — 재현됨.** fixed(2002-04~, 283개월): J1 t −3.078(|t|≥2.73, ≤−2), J2 과열 3 / 저평가 6 에피소드, J3 Sharpe 0.563 > 0.458 & 플라시보 99.6%, J4 후반부 t −3.52 → 시그널. 롤링은 t −1.52라 기각.

### 왜 통과하나 — "미래 정보"가 아니라 (a) 추세 비제거 + (b) 표본 시작월
| 방식 | 시작 | t | J2 과열/저평가 | J3 | J4 후반 t | 판정 |
|---|---|---|---|---|---|---|
| rolling | 2010-03 | −1.52 | 3/5 | 플라시보 72% 실패 | −0.91 | 기각 |
| fixed | 2002-04 | −3.08 | 3/6 | 통과 | −3.52 | 시그널 |
| **fixed_cut**(같은 시작월) | 2010-03 | **−2.76** | **1/4** | 통과 | −3.31 | **판정 보류** |
| fixed_cutstats | 2010-03 | −2.76 | 1/4 | 통과(98.9%) | −3.31 | 판정 보류 |
| **expanding**(미래 정보 없음) | 2010-03 | **−2.82** | 2/4 | 통과 | −1.98 | **판정 보류** |

1. **J2(에피소드)가 갈린 이유 = 표본 시작월.** 고정은 워밍업이 없어 2002-04~2010-02(95개월)를 신호 구간으로 쓴다. 이 구간에 과열 에피소드 2개(2005-11~2006-04, 2006-11~2008-05)가 있다. rolling 시작월(2010-03)로 자르면 과열 에피소드는 2010-12~2011-04 하나뿐 → J2 실패 → 판정 보류. 시그널 → 보류 하락의 직접 원인.
2. **t가 −1.52 → −2.76으로 커지는 이유 = 추세 비제거(롤링 z가 PBR의 장기 하락 추세를 지움), 미래 정보 아님.** 같은 표본(2010-03~)에서 fixed_cut −2.76, 과거만 쓰는 expanding −2.82로 거의 같다. 미래 정보를 빼도(expanding) t가 오히려 약간 더 큼 → 미래 정보의 기여는 사실상 0. KOSPI PBR은 전체 평균 1.175(σ 0.262)인데 롤링 평균은 1.27(2010)→1.09(2026)로 내려가 롤링 z는 '저점이 계속 낮아지는' 신호를 상쇄한다. PREREG 롤링 10년은 사전 등록한 디트렌딩이므로 이 차이는 정의의 결과다.
3. **J1 여유가 매우 얇다**: fixed_cut t −2.76은 기준 2.73에 0.03 차이. 2008·2009·2025 연도 제외 시 fixed −2.77/−3.05/−2.88(유지). 같은 표본에서 KOSPI PBR 시그널 판정은 판정 보류다.
4. 해석 주의: fixed의 평균·σ는 2026-11까지의 전 표본이라 신호 시점 t에 미리 알 수 없는 값이지만(미래 정보 포함 맞음), 이 지표에서는 영향이 미미(expanding과 비교). t 증가분은 '긴 기억 기준선(fixed·expanding) vs 10년 롤링'의 차이로 보는 게 맞다. 현재 z(2026-11 부분월 PBR 1.42): rolling +1.07 / fixed +0.93 / expanding +0.93.

## 3. 다른 5조합 (참고)
- KOSPI PER, S&P PER/PBR, KOSDAQ PER: 모든 방식에서 기각(|t|<1.1, 잘라도 동일). fixed 표본 확장은 판정을 바꾸지 않음.
- KOSDAQ PBR: 5방식 전부 판정 보류(J1·J4 통과, J2 실패). 잘라서 fixed_cut이면 t −6.44, 에피소드 과열 4/저평가 0 → 한쪽 에피소드가 없어 J2 실패. fixed_cutstats는 2/4, expanding 4/0 — **과열/저평가 에피소드 배분이 정의에 매우 민감**. J3 플라시보는 fixed 0.900(경계), rolling 0.828로 J3 불통과/경계.
- S&P PER fixed 플라시보 0.105 / fixed_cut 0.074 / fixed_cutstats 0.015: 신호가 '반대로' 작동(플라시보보다 못함).
