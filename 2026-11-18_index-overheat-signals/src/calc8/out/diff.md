## 2. 핵심 확인 사항: `KOSDAQ PBR` 3년 창

- **전체 3년 창 (`same_start=False`, `2008-02` 시작, `n=226`)**:
  - `t12 = -3.330637` (`|t| >= 3.21` 통과), `t12_half = -4.474964` (`< 0`), `ep_hot = 4`, `ep_cold = 5`, `sh = 0.1539 > c60 = 0.1521`, `placebo = 0.5300` (`< 0.90`, J3 실패) → **`참고지표`** 재현 확인.
- **10년 창과 동일 시작월 (`same_start=True`, `2013-09` 시작, `n=159`)**:
  - `t12 = -2.639777` (`|t| < 3.21`, J1 실패), `t12_half = -3.443850`, `ep_hot = 4`, `ep_cold = 4`, `sh = 0.2371 > c60 = 0.2254`, `placebo = 0.5489` → **`기각`** 재현 확인.
- **해석**: 3년 창에서 `참고지표`가 나온 이유는 워밍업 단축으로 `2008-02 ~ 2013-08` 구간이 추가된 **표본 시작월 효과**이며, 동일 표본(`2013-09~`)으로 맞추면 기각된다.

## 3. 기타 참고 (모호점/관찰)

- **선행 PER `z_now`**: `PREREG.md` 8절에는 마지막 주를 사진 표기값(`14.4, 18.9, 18.1`)으로 대체해 현재 `z`만 산출한다고 되어 있으나, `out/windows_stats.csv`의 `z_now`는 `data/agy/fwdpe_img*.csv` 원자료 마지막 주(`14.937, 19.454, 18.396`) 그대로 계산한 값과 일치한다(미확정 말단이라 회귀·판정에는 영향 없음).
- **모수 격자**: `PREREG.md` 12절 고정 창(`3y/5y/10y`)만 재계산하여 별도 격자 탐색은 수행하지 않았으며, 전체 64행 결과를 `calc8/out/recalc.csv`에 저장했다.
