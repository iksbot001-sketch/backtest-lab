# TASK_digitize — 사진 차트 디지털화 (Antigravity)

작업 폴더 안에서만. 코드는 `digitize/`, 결과는 `data/agy/` 와 `digitize/REPORT.md`. 다른 파일 수정 금지. 인터넷 불필요.

## 입력 (휴대폰 화면을 찍은 사진, 약간의 원근 왜곡·반사 있음)
- data/charts/img1.jpg — SOX 선행 PER, 주간 2016-11-17~2026-11-17. y축 10.0~30.0. 표기: 평균 19.2, +1σ 23.5, −1σ 15.0, 현재 14.4, 고점 29.0(2024-06-14), 저점 11.2(2018-10-26).
- data/charts/img2.jpg — 선행 PER(지수명 미표기), 주간 2017~2026-11-09. y축 16x~32x. 표기: 10년 평균 23.7, +1σ 26.9, −1σ 20.4, 2026-11-09 18.9.
- data/charts/img3.jpg — 선행 PER(지수명 미표기), 주간 2017~2026-11-09. y축 12x~24x. 표기: 평균 19.2, +1σ 21.3, −1σ 17.0, 2026-11-09 18.1.
- data/charts/img4.jpg — img1과 같은 SOX 차트의 다른 판(현재 15.1, 2026-11-09). img1 검증용.

## 할 일
1. 각 사진에서 검은/짙은 회색 시계열 선만 추출(점선 기준선·글자·배경 제외). 원근 보정이 필요하면 축 모서리 4점으로 보정.
2. 축 보정: y는 눈금 라벨 최소 2개 이상, x는 연도 눈금으로 선형 보정.
3. 주간(금요일) 시계열로 리샘플: `data/agy/fwdpe_img1_sox.csv`, `fwdpe_img2.csv`, `fwdpe_img3.csv` (columns: date,fwd_pe).
4. 검증표(REPORT.md): 각 차트의 표기값 vs 디지털화 값 — 전체 평균, 평균±표준편차(ddof=1), 마지막 값, 최고·최저(날짜 포함). img1과 img4 겹치는 구간 상관·평균 오차.
5. 오차가 ±0.5배를 넘는 항목은 원인과 함께 명시. 임의로 맞추지 말 것(평균을 표기값에 강제로 맞추는 스케일 조정 금지).
6. img2·img3가 어떤 지수인지 근거(수준·2020~21 고점·2022 저점 모양)로 추정만 적어라.
