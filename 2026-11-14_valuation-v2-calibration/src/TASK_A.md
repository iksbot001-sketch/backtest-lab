## 엔진 입력
```python
import sys; sys.path.insert(0, "src"); import engine as E
seg = E.Seg(ticker, [rev0, rev1, rev2, rev3], [m1, m2, m3], 0.21, sc)       # inputs.csv의 열 그대로
V = E.value([seg], r, h, lag=0.75, net_cash=net_cash)     # 주주가치, 매출과 같은 단위
```
- 세율 0.21 고정. 계산이 느리면(관측 6,792 × 반감기 탐색) multiprocessing을 써도 된다.
- `r` 두 가지: (가) 0.09 고정 [주 분석] (나) 아래 연도별 값 [보조]. (나)는 Claude가 기억으로 적은 근사치(10년 국채 + Damodaran 내재 위험프리미엄)라 보조로만 쓴다.

## 관측마다 계산할 것 (out/panel.csv)
inputs.csv의 모든 열에 아래 열을 더한다.
- `VP4`, `VP8`, `VP12`, `VP20` = V(h) ÷ 시가총액 (r = 0.09)
- `VP4_rt` = V(4) ÷ 시가총액 (r = 연도별 값)
- `h_star` = V(h) = 시가총액이 되는 h. 0.5~100 사이 이분법. V(100) < 시총이면 100, V(0.5) > 시총이면 0.5로 적고 `h_cap` 열에 "hi"/"lo" 표시. (r = 0.09)
- `h_star_rt` = 같은 것, r = 연도별 값

## 집계 표 (out/T1~T6.csv 와 REPORT.md에 같은 표)
그룹 정의: **전체** / **기술** (Sector가 Technology 또는 Communication Services) / **고수익** (그해 ROIC 상위 1/3) / **대표 15종목** (AAPL, MSFT, GOOGL, AMZN, META, NVDA, AVGO, ORCL, ADBE, CRM, NFLX, V, MA, COST, INTU)

- **T1 통과율.** 그룹별·연도별로 VP4 ≥ 1.0 인 비율, VP4 ≥ 0.8 인 비율, 관측 수. 전체 기간 합계 행 포함. 같은 표를 VP8, VP12, VP20, VP4_rt 로도.
- **T2 대표 15종목 행렬.** 행 = 종목, 열 = 연도, 값 = VP4. 그리고 같은 모양으로 h_star.
- **T3 내재 반감기 분포.** 그룹별·연도별 h_star의 25%·중앙·75% 지점, "hi"(100년으로도 못 미침) 비율, "lo" 비율. h_star_rt 로도.
- **T4 예측력.** 해마다 VP4로 3분위(낮음·중간·높음)를 나눠 이후 ex3, ex5의 평균과 중앙값. 전체 기간 평균, 그리고 "높음 − 낮음"이 양수인 해의 비율. 같은 것을 h_star 3분위로(낮은 h_star = 시장이 짧은 해자를 가정). 그룹은 전체와 기술 두 가지.
- **T5 놓친 종목.** ret5 상위 10% 관측 중 VP4 ≥ 1.0 이었던 비율, VP4 ≥ 0.8 이었던 비율. 비교용으로 전체 관측의 같은 비율. 그리고 VP4 ≥ 1.0 이었던 관측의 ret5 중앙값과 ex5 중앙값 대 그렇지 않은 관측.
- **T6 상대 평가.** 해마다 전체 그룹 h_star 중앙값을 h_mkt 로 두고 VP_mkt = V(h_mkt) ÷ 시가총액 을 다시 계산. VP_mkt 3분위별 이후 ex3, ex5 (T4와 같은 형식). 연도별 h_mkt 값도 표로.
