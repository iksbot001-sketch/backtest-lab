# TASK: 가치평가 엔진 v2 사전(ex-ante) 검증 (Claude Code 작성, 2026-11-15). 담당: Antigravity

## 왜 하나
보정 백테스트(2026-11-14)는 3년 실적을 **실현값**으로 넣었다. 이번에는 **평가일에 알 수 있던 정보만** 넣는다. 질문은 하나다.
"그때의 컨센서스로 계산한 적정가 ÷ 주가 순위가 이후 3년 초과수익을 맞혔는가, 그리고 단순한 선행 이익수익률(E/P)보다 나았는가."
절대 수준(적정가 > 주가)은 시험하지 않는다. 순위만 본다.

## 규칙

- 아래 정의·가설·판정 기준은 미리 고정한 것이다. 결과를 보고 바꾸지 않는다. 추가로 해 보고 싶은 분석은 `out/EXTRA.md`에 따로 적는다.

## 입력 `data/inputs.csv` (2,202행, 462종목, FY t = 2017~2022)
보정 백테스트와 같은 열(ticker, sector, t, eval_date, mktcap, rev0~rev3, m1~m3, sc, roic, net_cash, ret3, ret5, spy3, spy5, ex3, ex5) +
- `m0`: FY t 영업이익률(실적) · `ni0`: FY t 순이익
- `rev1_cons`: FY t+1 매출 컨센서스(FY t 말 무렵 마지막 스냅샷) · `g1c` = rev1_cons ÷ rev0 − 1
- `gec`: FY t+1 EPS 컨센서스 증가율 · `n_analysts`
- `ey_fwd`: 선행 이익수익률 = ni0 × (1 + gec) ÷ mktcap (순이익 ≤ 0이면 빈칸)
- **rev1~rev3, m1~m3 는 실현값이다. 사전 신호(E1, E2) 계산에 쓰면 안 된다.** 오라클(O) 비교에만 쓴다.

## 신호 (관측마다, r = 0.09, 세율 0.21, lag = 0.75, net_cash 포함. 엔진 호출은 보정 백테스트 calib.py 와 같다)
`E.value([E.Seg(tk, rev, m, 0.21, sc)], 0.09, h, lag=0.75, net_cash=net_cash) / mktcap`
- **E1** 매출 경로 rev = [rev0, rev0(1+g1), ·(1+g2), ·(1+g3)], g1 = g1c, g2 = 0.04 + 0.5(g1 − 0.04), g3 = 0.04 + 0.25(g1 − 0.04). 이익률 m = [m0, m0, m0].
- **E2** 매출은 E1과 같다. 이익률 m1 = m0 × (1 + gec) ÷ (1 + g1c) 를 [0.5·m0, 1.5·m0] 로 자르고 m = [m1, m1, m1]. gec 가 빈칸이거나 ni0 ≤ 0 이면 m1 = m0. m0 ≤ 0 이면 E1·E2 모두 빈칸.
- **O** 오라클: rev = [rev0, rev1, rev2, rev3], m = [m1, m2, m3] (실현값). 비교 기준.
- 열 이름: `VP_E1_4`, `VP_E2_4`, `VP_E2_8`, `VP_O_4` (끝 숫자 = 반감기 h). `hs_E2` = VP_E2 가 1 이 되는 h(0.5~100 이분법, 끝에 닿으면 0.5 또는 100).
- 비교용 단순 신호: `ey_fwd`, `sy_fwd` = rev1_cons ÷ mktcap.

## 표 (out/*.csv 와 out/REPORT.md 에 같은 표)
각 신호 S ∈ {VP_E1_4, VP_E2_4, VP_E2_8, VP_O_4, hs_E2(작을수록 싼 것이므로 부호를 뒤집어 −hs_E2), ey_fwd, sy_fwd} 에 대해:
- **A. 3분위 초과수익.** 해마다 S 3분위(값이 클수록 '싸다' = 상위)로 나눠 ex3 평균·중앙값. 연도별 행 + 전체 평균 행. 상위 − 하위 차이와 양수인 해의 수. ex5 도 같은 형식(t = 2017~2020만).
- **B. 순위 상관(IC).** 해마다 S 와 ex3 의 스피어만 상관. 연도별 값, 평균, 표준편차, 평균 ÷ (표준편차 ÷ √연도 수).
- **C. 업종 중립.** 해마다 sector 안에서 S 의 백분위 순위를 매긴 뒤(관측 5개 미만 sector 는 제외) A·B 를 다시.
- **D. 통과율.** 해마다 VP_E2_4 ≥ 1 비율과 VP_O_4 ≥ 1 비율, 그룹 전체 / 기술(Technology·Communication Services) / 고수익(그해 roic 상위 1/3).
- **E. 신호 사이 상관.** 전체 관측에서 S 들 사이 스피어만 상관 행렬.
- **F. 컨센서스 오차.** 해마다 g1c 와 실현 (rev1 ÷ rev0 − 1) 의 평균 차이와 상관.

## 미리 정한 판정 (REPORT.md 맨 위에 '충족/미충족' 만 적는다)
